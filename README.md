# 🖥️ Aaryan OS

> A premium, fully interactive web-based operating system simulation built with HTML, CSS, and Vanilla JavaScript.

**Aaryan OS** is a browser-based operating system simulation designed to recreate the experience of using a modern desktop operating system. From a cinematic boot sequence and lock screen to a fully interactive desktop, window management system, applications, terminal, and persistent storage — everything runs directly inside the browser.

> ⚠️ **Note:** Aaryan OS is a web-based simulation and is not a real bootable operating system.

### 🪟 Window Management System

Aaryan OS includes a dynamic window management system.

Windows can be:

* Opened
* Closed
* Minimized
* Maximized
* Restored
* Dragged
* Resized
* Focused
* Managed using dynamic z-index

Multiple applications can run at the same time.

### 💻 Aaryan Terminal

Example:


```text
history
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder:

```bash
cd aaryan-os
```

Then open:

```text
index.html
```

You can also run it using a local development server such as **VS Code Live Server**.
